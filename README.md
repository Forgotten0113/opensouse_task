# 간단한 편집 기능을 갖춘, 최대한 가벼운 동영상 플레이어 프로그램 개발

**가볍게 영상을 재생하고, 필요한 부분만 간단히 편집하는 Windows 프로그램**입니다.

mpv.net을 기반으로 화면과 메뉴를 수정하고, FFmpeg로 편집 결과를 새 파일에 저장할 계획입니다.

## 프로젝트 목표

- 일반적인 영상 플레이어처럼 빠르고 간단하게 사용합니다.
- 복잡한 타임라인 대신 메뉴와 작은 편집 창을 사용합니다.
- **편집할 때만 FFmpeg를 실행**합니다.
- 원본을 유지하고 편집 결과는 별도 파일로 저장합니다.

## 사용 기술

| 기술 | 역할 |
| --- | --- |
| C# / .NET | 화면 수정 및 편집 작업 관리 |
| mpv.net | 기존 플레이어와 GUI의 기반 |
| libmpv | 영상 재생, 탐색, 재생 음량 조절 |
| FFmpeg | 구간 삭제, 영상 연결, 게인 적용 및 저장 |
| ffprobe | 길이, 코덱, 해상도, 트랙 정보 확인 |

## 주요 기능

### 1. 기본 재생

- 영상 및 음악 파일 열기
- 여러 파일 또는 폴더 열기
- 재생 / 일시정지
- 처음으로 이동 및 다음 영상 이동
- `n초` 뒤로 / 앞으로 이동
- 재생 위치와 시간 표시

### 2. 재생 음량

- 슬라이더 범위는 **0~200%** 입니다.
- 중앙은 `100%`이며, 숫자는 현재 음량을 나타냅니다.
- 숫자를 클릭해 값을 직접 입력할 수 있게 합니다.
- `200%`를 넘겨 입력하면 손잡이는 오른쪽 끝에 두고 입력값을 적용합니다.

> 재생 음량을 바꾸는 것만으로 원본 파일이 변경되지는 않습니다.

### 3. 앞부분 미리보기

파일의 처음부터 **k초 동안** 재생합니다.
`k`는 Config 메뉴에서 변경합니다.

원격 영상도 전체 다운로드 없이 미리보기를 시도합니다.

### 4. 간단한 편집

| 기능 | 동작 |
| --- | --- |
| 구간 삭제 | 여러 삭제 구간을 지정하고 나머지를 연결 |
| 영상 이어붙이기 | 다른 영상을 현재 영상의 앞 또는 뒤에 추가 |
| 현재 음량값 적용 | 현재 재생 음량 배율을 파일의 오디오에 적용 |
| 임의 게인 입력 | dB 또는 % 중 하나로 값을 입력해 적용 |

**적용 버튼을 누르면 새 파일 생성 작업을 바로 시작합니다.**

완료까지는 편집 내용에 따라 시간이 걸리며, 원본 파일은 유지합니다.

### 5. 설정 메뉴

- `n`: 앞뒤 이동 간격
- `k`: 미리보기 시간
- 단축키 설정
- 출력 파일 이름 설정

## 편집 과정

1. 파일을 엽니다.
2. Edit 메뉴에서 작업을 선택합니다.
3. 구간, 연결할 파일 또는 게인값을 입력합니다.
4. **적용** 버튼을 누릅니다.
5. 프로그램이 FFmpeg를 별도 프로세스로 실행합니다.
6. 진행률을 표시하고 새 파일을 저장합니다.
7. 완료 또는 오류를 알립니다.
